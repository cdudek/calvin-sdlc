Two colour worlds. Never mix them.

The system carries two separate palettes. Determine the asset type before every colour decision, then work exclusively in the matching colour world. The default is Editorial & Advertising. If the asset type is unclear, ask before setting a colour.

Colour world 1 — Web & Product (UI)

Semantic UI tokens from "Background colors" and "Brand palette": bg-surface, bg-surface-elevation-*, text-main, border-main, bg-primary-*, status colours. Only for surfaces that end in code.

Colour world 2 — Editorial & Advertising (brand kit)

Eleven binding hex values from "Graphic / chart colours". For everything designed outside the product. Always output colours as hex, token names only as a supplement: external tools and image generators cannot resolve token names.

The only exception: bg-primary-subtlest #f4f2ff and bg-secondary-subtlest #fef9e8 may also be used in colour world 2. Exclusively as box and surface backgrounds (callouts, cards, table rows, quote boxes). Not for text, icons, lines, chart series or full-bleed backgrounds. This is not a general permeability between the colour worlds.
