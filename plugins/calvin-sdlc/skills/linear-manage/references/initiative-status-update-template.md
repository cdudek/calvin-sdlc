# Initiative Status Update Template

**Linear object:** Status Update (on an Initiative)

## MCP Steps

```
save_status_update:
  initiative: "<initiative-name>"
  health: "onTrack"  # onTrack | atRisk | offTrack
  icon: ":bar_chart:"
```

Then update with content.

## Template

```markdown
## Summary
One paragraph: strategic progress this period and overall trajectory.

## Key Results Progress
| Key Result | Baseline | Current | Target | Status |
|-----------|----------|---------|--------|--------|
|           |          |         |        |        |

## Project Health
| Project | Health | Summary |
|---------|--------|---------|
|         |        |         |

## Strategic Updates
- Any shifts in direction, new opportunities, or deprioritizations

## Risks & Escalations
| Risk | Impact | Status | Owner |
|------|--------|--------|-------|
|      |        |        |       |

## Next Period Focus
- Priority 1
- Priority 2
- Priority 3
```

Uses the same health status guide as Project Status Updates (`onTrack` / `atRisk` / `offTrack`).
