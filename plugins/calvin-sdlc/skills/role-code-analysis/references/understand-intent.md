# Understand Intent

Feedback (review comments, bug reports, ticket descriptions) points at a problem. The suggested fix is one possible solution, not a mandate.

## Approach

- Read the relevant modules and gain deep understanding of the domain before proposing changes
- Investigate the problem independently — don't just apply whatever was suggested verbatim
- Use web search and documentation if the domain is unfamiliar
- Identify what the actual underlying problem is, which may differ from what was literally described
- Consider: is the reporter describing a symptom or a root cause?

The goal is to fix the underlying problem, not to mechanically apply a suggested patch.
