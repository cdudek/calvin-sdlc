# The owner's words

Every request the owner has made about the interface, verbatim, dated, grouped by topic. All of
these were made in the build conversation on 2026-09-25. A quote may appear under more than one
topic when it covers both.

## Purpose and output

> "I need a tool where I can create screenshots and augment them:
>
> - draw on them
> - add crosses for a cross through
> - add nodes
> - put in references"
>
> — 2026-09-25

> "For instance mark something on the screen and then be able to write something in a Markdown doc where it puts the image automatically in the Markdown doc." — 2026-09-25

> "Also in a nutshell, it should then create a Markdown document including the images." — 2026-09-25

> "It's basically for providing feedback to AI in a nice and token-efficient way." — 2026-09-25

## Sessions

> "It needs to be some sort of project or session. If there's an existing session I just add to the existing session or I create a new session." — 2026-09-25

> "First I want to have the functionality that when I create a new session it creates Markdown. I can add screenshots to the Markdown and augment the Markdown: draw into the image, comment on it, and add a reference with text on certain elements, pretty much that." — 2026-09-25

> "I also wonder: where do I access the session? Is this in the toolbar of my Mac? Is this where I am supposed to see it or where would I see that?" — 2026-09-25
