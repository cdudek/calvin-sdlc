# Code Analysis Workflow

**Constraint (applies throughout):** [Protect tests](references/protect-tests.md) — tests are sacrosanct, change only as last resort. This governs all steps below.

1. **Understand intent** — parse the problem, not the literal suggestion → [references/understand-intent.md](references/understand-intent.md)
2. **Root cause analysis** — find why the defect was possible → [references/root-cause-analysis.md](references/root-cause-analysis.md)
3. **Generalize and sweep** — check if the issue applies elsewhere → [references/generalize-sweep.md](references/generalize-sweep.md)
4. **Evaluate approaches** — outline options for non-trivial fixes → [references/evaluate-approaches.md](references/evaluate-approaches.md)
5. **Categorize** — classify findings by type and severity → [references/categories.md](references/categories.md)
6. **Validate findings** — independently verify each finding → [references/validate-findings.md](references/validate-findings.md)
7. **Synthesize** — cluster, deduplicate, and rank → [references/synthesize.md](references/synthesize.md)
