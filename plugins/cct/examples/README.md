# Examples

Real documents from HeyDiff, copied on 2026-10-31, to show what each kickoff document looks like when it is done. Copy the shape; write your own content.

- `heydiff/context/`: the context repo. `CLAUDE.md` (index), `audience/` (audiences, personas, jobs to be done), `strategy/roadmap.md`, `design-system.md`, and the brand guide v4 exports (`brand-guide.md`, `implementation-brief.md`, `llms.txt`, `decisions.md`, `tokens/`, `manifest.json`).
- `heydiff/heydiff-brand-guide-selection.pdf`: the brand guide as a document: numbered pages, rules first, examples after, research in the appendix.
- `heydiff/web/docs/ux/`: the UX rules of a web app (setup, interaction guidelines, glossary proposal, owner's words, sitemap, states contract).
- `heydiff/desktop/docs/ux/`: the same for a desktop app, plus UX decisions and the impeccable config.
